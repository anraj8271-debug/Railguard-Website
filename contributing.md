# Contributing to RailGuard 🛡️

We welcome additions, code cleanups, and architectural improvements to the RailGuard Offline Mesh system! As a prototype framework developed under the **Hack for Social Cause** campaign, we aim to extend this implementation into real-world locomotive network paths.

## 🚀 How to Help Out

1. **Bug Identification & Testing:** Spin up the node server loop locally or execute the Python handler threads to run communication checks on alternative devices.
2. **Hardware Enhancements:** Modify firmware structures or configuration pathways to adapt the script interface outputs directly to physical ESP32 Wi-Fi NAN or BLE radio chips.
3. **Audio AI Expansion:** Train or tweak your own micro-TFLite sound processing model to scale vocal frequency tracking and test it right inside your app framework layers.

## 📋 Code Quality Checklist
Before packaging up any improvements for review:
* Run local performance tests to ensure background services (`WorkManager`/`BGTasks`) execute reliably without consuming heavy phone battery.
* Confirm that any payload modifications pass cleanly through JSON formatting rules so they don't break the live telemetry monitoring console.
